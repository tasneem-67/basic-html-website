# Basic HTML Website

A multi-page website built using HTML only, as part of the [roadmap.sh HTML Projects](https://roadmap.sh/projects/basic-html-website).

## Technologies
- HTML5

## Project Requirements
- Multiple HTML pages (Home, Projects, Articles, and Contact)
- Consistent navigation bar across all pages
- Semantic HTML structure
- SEO meta tags on every page
- Contact form with name, email, and message fields
- Proper heading hierarchy
- Internal page navigation
